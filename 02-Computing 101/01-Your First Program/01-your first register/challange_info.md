# Challenge: Your First Register

## 🛠️ Quick Access
👉 **[Direct Link to Challenge](https://pwn.college/computing-101/your-first-program/)**

## 🔗 Details
* **Dojo:** Computing 101
* **Module:** Your First Program
* **Target File:** `solve.s`

## 📝 Objective
Write a basic x86-64 Assembly statement to move a specific immediate integer value directly into a processor register.

## 💻 Verification Command
To check the source code file directly without manually building or linking an independent binary executable, pass the `.s` file directly to the platform's checker script:
```bash
/challenge/check solve.s
```

💡 **Dialect Note:** The platform's automated tester evaluates source logic using **Intel Syntax** configuration rules.
